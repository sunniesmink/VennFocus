1. Himpunan & Himpunan Semesta (S)

Definisi Formal:
• Himpunan adalah kumpulan objek terdefinisi secara jelas.
• Himpunan Semesta ($S$) adalah himpunan yang memuat seluruh objek/elemen yang sedang dibicarakan.

Contoh Kasus:
Misalkan $S = \{1, 2, 3, 4, 5, 6, 7, 8\}$
$A = \{2, 3, 5, 7\}$ (Bilangan Prima $< 8$)
$B = \{1, 3, 5, 7\}$ (Bilangan Ganjil $< 8$)

2. Irisan Dua Himpunan (A ∩ B)

Notasi Operasi: A ∩ B = {x | x ∈ A dan x ∈ B}
Irisan dari himpunan A dan B adalah himpunan yang anggotanya berada di A sekaligus berada di B.

Latihan Pemetaan Elementer:
Diketahui: $S = \{1, 2, 3, 4, 5, 6\}$, $A = \{1, 2, 3\}$, $B = \{3, 4, 5\}$.

3. Gabungan Dua Himpunan (A ∪ B)

Notasi Operasi: A ∪ B = {x | x ∈ A atau x ∈ B}
Gabungan dari himpunan A dan B mencakup seluruh elemen yang menjadi anggota A, anggota B, atau anggota kedua-duanya.

Contoh Soal:
Jika $A = \{a, b, c\}$ dan $B = \{c, d, e\}$, maka:
$A \cup B = \{a, b, c, d, e\}$

4. Selisih Dua Himpunan (A - B)

Notasi Operasi: A - B = {x | x ∈ A dan x ∉ B}
Selisih himpunan A dan B adalah kumpulan anggota yang murni hanya dimiliki A dan tidak dimiliki oleh B.

Contoh Soal:
Jika $A = \{1, 2, 3, 4\}$ dan $B = \{3, 4, 5, 6\}$, maka:
$A - B = \{1, 2\}$

5. Komplemen Himpunan (Aᶜ)

Notasi Operasi: Aᶜ = {x | x ∈ S dan x ∉ A}
Komplemen himpunan A adalah semua elemen dalam himpunan semesta ($S$) yang bukan merupakan anggota A.

Contoh Soal:
Jika $S = \{1, 2, 3, 4, 5\}$ dan $A = \{2, 4\}$, maka:
$A^c = \{1, 3, 5\}$
